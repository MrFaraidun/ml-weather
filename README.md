A machine learning meteorology and atmospheric prediction web application built with **Scikit-Learn**, **FastAPI**, and **React**. Uses historical weather data and ensemble regression algorithms to predict temperature variations, rainfall probability, and humidity trends across Kurdistan and global regions.

</div>

---

### // CORE FEATURES

* **Predictive ML Pipelines**: Scikit-Learn regression models trained on multi-year climate datasets.
* **Microsecond REST Endpoints**: High-performance asynchronous FastAPI prediction endpoints.
* **Interactive Data Visualization**: Real-time 7-day temperature curves and precipitation risk telemetry.
* **Atmospheric Sensor Integration**: Live weather APIs combined with local model inferencing.

---

### // TECH STACK

* **Machine Learning**: Scikit-Learn, Pandas, NumPy
* **Backend API**: Python 3, FastAPI, Uvicorn
* **Frontend**: React, Tailwind CSS, Recharts
* **Deployment**: Vercel Edge

---

### // QUICKSTART

```bash
# Clone repository
git clone https://github.com/MrFaraidun/ml-weather.git
cd ml-weather

# Install Python requirements
pip install -r requirements.txt 2>&1 || pip install fastapi uvicorn scikit-learn pandas

# Run backend API
python -m uvicorn main:app --reload

# Start frontend
npm install && npm run dev
```
